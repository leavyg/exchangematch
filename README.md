# ExchangeMatch

Every 2027/28 Trinity College Dublin exchange that fits your degree pathway, in one place: School and College-wide exchanges, shown separately, with the official source behind every fact.

**Live site:** https://leavyg.github.io/exchangematch/

- Data comes from Trinity's published partner lists and is being reviewed by exchange coordinators. Always confirm with your coordinator before applying.
- Favourites and rankings are saved in your own browser only.
- A student project. Not affiliated with Trinity College Dublin.

This repository holds the built website. `data.json` is generated from the ExchangeMatch data register.
